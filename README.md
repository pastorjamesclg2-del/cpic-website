# CPIC website (cpic.info)

Christ Power International Church, Dubai.

- `index.html` is **Ekklesia**, the public site: sermon notes, events and posters, and prayer requests by WhatsApp to Pastor James or Pastor Blessing James.
- `manifest.webmanifest`, `sw.js` and the icons let people install the site as a phone app.
- Netlify publishes this folder automatically whenever this repository changes (see `netlify.toml`).

Planned: **Shepherd**, the workers-only area at `/shepherd`, with invite-only sign-in.
